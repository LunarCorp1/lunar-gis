# Technical Documentation

Use when writing `docs/` or updating ADRs.

## When to use

* Creating/editing `docs/adr/*`, `docs/architecture/*`, `docs/README.md`, skill docs

## Must do

* Follow `AGENTS.md:31` — update documentation/ADR when architecture changes; read `docs/adr/README.md` template (Status, Date, Context, Decision, Alternatives, Consequences) before adding ADR.
* Use `docs/adr/ADR-0001..0005` as style references; keep `docs/adr/README.md` index current.
* Keep language precise, link to `AGENTS.md`, `SECURITY_MODEL.md`, `PROVIDER_CONTRACT.md` where relevant.

## References

* `AGENTS.md`, `docs/adr/README.md`, `docs/architecture/OVERVIEW.md`, `docs/architecture/MILESTONES.md`

## Checklist

* [ ] New ADR has Status/Date/Context/Decision/Alternatives/Consequences and Related links
* [ ] `docs/adr/README.md` index updated
