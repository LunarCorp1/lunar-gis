# Data Provider Contract

All remote data integrations should implement a bounded provider contract.

Conceptual interface:

```python
class DataProvider:
    def search(self, request): ...
    def get_metadata(self, dataset_id): ...
    def get_assets(self, dataset_id): ...
    def download(self, asset, destination): ...
    def connect(self, resource): ...
    def attribution(self, dataset_id): ...
    def license(self, dataset_id): ...
```

The AI requests data through this abstraction instead of issuing arbitrary HTTP downloads.
